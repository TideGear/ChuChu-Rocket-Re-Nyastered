# Dreamcast progress preview

This preview makes the Dreamcast-only path more complete and shows the work since v2026.11.20. Visual and audio matching is still in progress.

## Improvements

- Native Dreamcast Puzzle Stage Select, using the disc's numbered capsules, difficulty selector, hint bubble and 3D board preview.
- Puzzle clear artwork and working Next / Stage Select controls after the original result delay. Keyboard, mouse and controller continuation are connected.
- Fixed the detached vertical line near the pulsing cursor. All 16 tested pulse phases now match the original separate cursor texture exactly in the accelerated-renderer comparison.
- More native Dreamcast presentation: recorded attract-demo input, roulette, crowns and special-mouse markers, animated mouse ghosts, corrected cat walk timing, and improved floor sampling.
- Corrected board-arrow size from the original draw data. The aligned Battle reference frame now has mean RGB error about 5.5, improved from 5.95 before this size correction; full visual parity requires 3 or less.
- Included the font/exporter dependencies needed by packaged disc-only setup.

## Known unfinished work

- Dreamcast-only sound effects are not connected yet. Music and sound effects are separate paths.
- Puzzle shuttle launch, flame and smoke are not implemented in this preview; the clear result and continuation work, but the rockets remain parked.
- Some menu routes, alternate stage sets, effects and animation details still differ from the original. This is not a claim of complete Dreamcast support.
- Runtime hint/clock text uses bundled fallback fonts without a BIOS. Supplying your own supported BIOS allows the original glyphs; no BIOS is included or required to play.

## Setup and checks

Use your own game files. A tested USA Dreamcast CUE/BIN image alone is sufficient for extraction and play; no mobile release or BIOS is required. Game data, extracted artwork, BIOS images and saves are not distributed.

After updating, rerun Easy Setup in RecompLauncher (or `ccr --prepare`) so the new disc UI and cursor atlases are exported. Merely replacing the executable leaves older extracted assets unchanged.

The Windows archive was tested through its packaged setup into a fresh folder with the disc image alone. Headless checks cover startup, Mode Select, Puzzle Stage Select, the attract demo, Stage Challenge selection/play, and a natural Puzzle 01 clear followed by both Next and Stage Select. The native Puzzle selector's measured full-frame mean RGB error is 2.25 against the captured original; hint/preview residue remains.

Regression checks: 180,000 deterministic replay ticks with no divergence; 26/26 Battle cases; 10/10 CPU cases; Dreamcast RNG, 25-board invariants, save/data, pad mapping and data-free VMU tests pass. Windows uses a static C/C++ runtime.

Unofficial fan project, unaffiliated with SEGA.
