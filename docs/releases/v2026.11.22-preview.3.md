# Dreamcast progress preview 3 (hotfix for preview 2)

Fixes two problems found while testing preview 2. Everything else is unchanged from [preview 2](v2026.11.22-preview.2.md).

## Fixes

- **Mouse clicks landed in the wrong place on the Dreamcast screens** (for example, clicking stage 25 in Puzzle Stage Select selected stage 8). SDL rewrites mouse positions into the screen's drawing coordinates, and each screen then converted them a second time, so clicks landed at 0.625 of the target whenever the window was not exactly the screen's native size. All screens now convert once. Found with the new `CCR_MOUSEDBG=1` click log, which writes `mousedebug.log` with the window size and converted position of each click.
- **Invisible rocket after updating from an older install.** The rocket body, base and flame come from art exported by setup; installs that kept art extracted by an older version drew the dome lids but not the rocket. The game now detects out-of-date Dreamcast art (a version stamp written by setup) and shows a message asking you to run Easy Setup again (or `ccr --prepare`).

## Updating

Run Easy Setup again in RecompLauncher (or `ccr --prepare`) after updating, as for preview 2; the game will remind you if you forget.

## Known unfinished work

Unchanged: Dreamcast sound effects are not connected; no controller path to the Puzzle pause menu; the Battle round-start caption, star twinkles and Keyboard F-key page are not drawn or built; Options General and 4P settings do not change game rules yet; Jump Pack has no effect; look-alike fonts without a BIOS. Details in the preview 2 notes and `docs/audit.md`.
