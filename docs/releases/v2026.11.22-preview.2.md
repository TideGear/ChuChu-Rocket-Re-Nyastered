# Dreamcast progress preview 2

This preview closes much of the visual gap to the Dreamcast original. Every comparison below is against frames captured from the real game in Flycast, using only the disc image (no mobile files, no BIOS). Sound effects are still not connected.

## Improvements

- **Much closer picture.** A new comparison harness (`tools/parity.py`) re-measures 123 Flycast frames in one command on a clean disc-only extraction. 120 are within a mean RGB error of 3 (the exceptions: launch frame 0 at 3.8, and the General and 4P Options pages at 5.0 and 4.3, which use look-alike text) (it was 7-8 on Puzzle and 5-6 on Battle at the last preview): Puzzle play 1.2, Puzzle clear and save notice 1.2, the Challenge intro 0.7, Challenge play 1.8, Mode Select 0.9, Challenge select 2.0, Battle 2.2, and all 22 Help screens 0.3-0.65. Method and the full table are in `docs/roadmap.md` and `docs/audit.md`.
- **Puzzle rocket launch.** Lifting bodies, opening lids, bases, flame and smoke, checked frame by frame against the original from nine frames before launch to 80 after: 89 of 90 frames pass; the first launch frame does not (see below).
- **Exact backgrounds and colours.** Puzzle, Challenge and Battle use the Dreamcast background colour; the floor uses the original's integer vertex colour (203/255) and its real sampling, which removed the cell-edge seams.
- **Puzzle and Help screens drawn at the original quad positions** with the original texture coordinate span; the Help frames, strips and page art now line up.
- **Cell cursor in the right layer** (walls cover parts of the corner bracket, as in the original) in Puzzle, Challenge and Battle.
- **Two-colour rocket domes** in Challenge and Team Battle, built from two lids in the two players' colours.
- **Options screen sub-pages:** Language (sets the game language), Records (Stage Challenge total time and stages cleared), General Settings and Settings for 4P Battle and Team Battle. The two settings pages draw correctly and change their values; the values are not connected to the game rules yet.
- **Dreamcast Help screens:** all 21 pages checked against the original.
- Goal rules, audit table and notes updated; the comparison tools (`parity.py`, `diff_heatmap.py`, `oracle/dc_layers.py`) are in the source tree.

## Known unfinished work

- Dreamcast sound effects are not connected yet.
- Puzzle: no controller path to the Pause menu; the first launch frame still draws parked domes where the original draws none; the background star twinkles are not drawn.
- Battle: the "START" caption at round start is not drawn; Team Battle and other Challenge stages are only partly compared.
- Options: the Keyboard F-key page is not built (it assigns quick-chat messages, an online feature); General and 4P settings do not yet change the game; Jump Pack has no effect.
- Runtime text (hint bubble, clocks, Options text) uses bundled look-alike fonts unless you supply your own BIOS, so it differs from the original glyphs in disc-only installs.
- Puzzle Edit, Network and Homepage are not available.

## Setup and checks

Use your own game files. A tested USA Dreamcast CUE/BIN image alone is sufficient for extraction and play; no mobile release or BIOS is required. Game data, extracted artwork, BIOS images and saves are never included.

After updating, rerun Easy Setup in RecompLauncher (or `ccr --prepare`) so the new disc UI atlases (Puzzle HUD, Help pages, Options) are exported. Replacing only the executable leaves older extracted assets and the old picture.

Comparison details: the accelerated renderer was used for the numbers (`CCR_GPU=1`, 640x480, hidden window); the software renderer overstates sprite error. Differences of 1-2 colour levels are the capture GPU's rounding, not rendering errors.
